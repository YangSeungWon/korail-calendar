# 승차권 → 캘린더

아이폰 승차권 목록 화면을 찍으면 열차 일정을 캘린더에 넣어주는 단축어입니다.

서버도, 로그인도, AI API도 쓰지 않습니다. 아이폰에 들어 있는 문자 인식과 캘린더 액션만 씁니다. 승차권 이미지는 기기 밖으로 나가지 않습니다.

```
2030-09-23 서울 19:10 → 부산 21:50     ← 인식된 후보에서 고르면
🚅 서울 → 부산                          ← 캘린더에 이렇게 들어갑니다
2030-09-23 19:10 – 21:50 · 30분 전 알림
```

## 설치

[**Releases**](../../releases/latest)에서 `korail-calendar.shortcut`을 아이폰으로 내려받아 엽니다. Mac에서 받았다면 AirDrop으로 아이폰에 보내세요.

파일을 열면 단축어 앱이 열리고 미리보기가 뜹니다. 맨 아래 **‘단축어 추가’**를 누르면 설치됩니다.

> 처음 설치할 때 ‘신뢰할 수 없는 단축어’ 경고가 뜨면 `설정 → 단축어 → 신뢰할 수 없는 단축어 허용`을 켜야 합니다. 이 항목은 단축어를 한 번이라도 실행한 뒤에 나타납니다.

## 처음 한 번만: 설정

### 1. 저장할 캘린더 고르기

기본값은 **‘집’** 캘린더입니다. 다른 곳에 넣으려면:

1. 단축어 앱에서 **승차권 캘린더**를 길게 눌러 **편집**
2. 아래로 내려 **‘새로운 이벤트 추가’** 액션을 찾습니다
3. **캘린더** 칸을 눌러 원하는 캘린더로 바꿉니다

기기에 ‘집’이라는 캘린더가 없으면 이 칸이 비어 있을 수 있습니다. 그때는 반드시 직접 골라야 합니다.

처음에는 **테스트용 캘린더를 새로 만들어** 지정하시길 권합니다. 잘 되는 걸 확인한 뒤 실제 캘린더로 바꾸면 정리가 쉽습니다.

### 2. 권한 허용

처음 실행하면 사진과 캘린더 접근을 물어봅니다. 둘 다 허용해야 합니다. 캘린더는 **쓰기뿐 아니라 읽기도** 필요합니다 — 이미 등록한 일정을 다시 넣지 않으려고 검색하기 때문입니다.

### 3. 뒷면 탭에 연결 (선택)

`설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭` (또는 삼중 탭) → 아래로 내려 **승차권 캘린더** 선택.

아이폰 뒷면을 두드리면 바로 실행됩니다.

## 쓰는 법

승차권 목록 화면에서 **날짜, 출발역, 도착역, 출발 시간, 도착 시간이 모두 보이게** 합니다. 실행 방법은 둘 중 아무거나:

| | 방법 | 장점 |
|---|---|---|
| **뒷면 탭** | 목록을 띄운 채로 아이폰 뒷면을 두드립니다 | 손이 제일 적게 갑니다. 화면을 알아서 캡처합니다 |
| **공유 시트** | 스크린샷을 찍고 공유 → 승차권 캘린더 | **여러 장을 한꺼번에** 넘길 수 있습니다 |

인식된 후보가 목록으로 뜹니다. 날짜·역·시간을 확인하고 등록할 것만 고른 뒤 완료를 누르면 됩니다.

### 승차권이 많을 때

단축어가 앱을 대신 스크롤해 주지는 못합니다. 스크롤하면서 **스크린샷을 여러 장 찍어두고**, 사진 앱에서 전부 선택해 **한 번에 공유**하세요. 화면이 겹쳐서 같은 승차권이 여러 장에 나와도 중복은 알아서 걸러집니다.

### 알아두면 좋은 것

- **중복은 건너뜁니다.** 날짜·역·시간이 같은 일정은 이벤트 메모에 심어둔 식별자로 찾아냅니다. 같은 캡처를 두 번 돌려도 일정이 두 개 생기지 않습니다. 단, 손으로 만든 일정에는 식별자가 없어서 중복으로 인식되지 않습니다.
- **제목은 `🚅 서울 → 부산`** 형식입니다. 화면에 열차 종류가 안 나오므로 KTX인지 SRT인지는 추측하지 않습니다.
- **30분 전 알림**이 붙습니다.
- 시각은 한국 시간(`+09:00`)으로 넣습니다.
- 끝나면 `추가 N개 · 중복 N개 · 확인 필요 N개` 요약이 뜹니다.
- **취소하거나 변경한 승차권은 따라가지 않습니다.** 캘린더에서 직접 지우거나 고쳐야 합니다.

## 안 될 때

**“완전히 보이는 승차권을 찾지 못했습니다”**
카드가 화면 위아래에 잘렸을 수 있습니다. 카드 하나가 통째로 보이도록 조금 스크롤한 뒤 다시 하세요.

**“카드를 온전히 읽지 못했습니다”**
출발 정보와 도착 정보의 개수가 맞지 않는 경우입니다. 잘못 짝지어진 일정을 만드느니 아무것도 안 만드는 쪽을 택합니다. 역시 카드가 온전히 보이게 조정하고 다시 하세요.

**후보는 뜨는데 캘린더에 안 들어감**
편집 화면에서 ‘새로운 이벤트 추가’ 액션의 캘린더 칸이 비어 있는지 확인하세요.

**역 이름이 이상하게 인식됨**
문자 인식이 틀린 경우입니다. 실재하는 역인지 확인하지 않으므로 선택 화면에서 걸러 주세요.

## 지원 범위

`YYYY.MM.DD`, ‘기차 승차권’, 역 두 개와 시간 두 개가 있는 목록 카드를 대상으로 합니다.

지원하지 않는 것: 자정을 넘는 이동, 승차권 상세 화면, 푸시 알림 문구, 2자리 연도, 월/일을 한 자리로 쓴 표기. 출발역과 도착역이 같거나 도착 시간이 출발 시간보다 이르거나 같은 후보는 등록하지 않습니다.

## 어떻게 동작하나

문자 인식에서 겪은 문제와 그 해법이 이 프로젝트의 거의 전부입니다.

**Apple Vision은 스크린샷을 카드 단위로 읽지 않습니다.** 실제 기기 출력에서는 화면 전체를 세로 열 단위로 읽어서, 카드 세 개의 왼쪽(날짜·출발역·출발시간)이 먼저 나오고 오른쪽(도착역·도착시간)이 그 뒤에 몰려 나왔습니다. 한 카드의 도착 정보가 다른 카드 두 개만큼 떨어지는 셈입니다. 게다가 이 순서는 고정도 아니라서, 같은 화면이라도 카드별로 묶여 나오는 경우가 있었습니다.

그래서 읽기 순서에 기대지 않습니다. **스크린샷을 세로로 반 잘라 각각 문자 인식을 돌립니다.** 카드 레이아웃상 출발역·출발시간은 항상 왼쪽, 도착역·도착시간은 항상 오른쪽입니다. 잘린 각 절반은 좁은 단일 열이라 위에서 아래로 읽힐 수밖에 없고, 그러면 N번째 출발과 N번째 도착이 순번으로 짝지어집니다.

양쪽 모두 **파란 머리말 줄**을 기준점으로 씁니다 — 왼쪽은 날짜, 오른쪽은 같은 높이에 있는 `N일 전`. 스크롤하다 카드가 화면 경계에 걸리면 이 줄이 양쪽에서 동시에 사라지므로, 그 카드만 빠지고 나머지는 순번이 그대로 맞습니다. 오른쪽을 아래의 `1매` 줄에 걸면 날짜만 잘렸을 때 개수가 어긋나 스크린샷 전체가 버려집니다.

그래도 짝짓기가 순번 기반이라, **양쪽 개수가 다르면 그 이미지에서는 아무것도 등록하지 않습니다.** 억지로 짝지으면 그럴듯하지만 틀린 일정이 생기기 때문입니다.

머리말과 역 사이에 끼어드는 필터 칩(‘이용권’, ‘정기권’)과 탭바(‘홈’)는 **숫자 없는 줄 건너뛰기**로 넘깁니다. 날짜와 시간 줄에는 항상 숫자가 있으므로 이 건너뛰기가 옆 카드까지 넘어가지 않습니다.

기기에서 확인한 제약이 하나 더 있습니다. `일치하는 텍스트에서 그룹 가져오기`가 **어떤 인덱스로도 빈 값을 반환합니다.** 그래서 캡처 그룹을 읽지 않고, 필요한 값은 전부 `텍스트 대치`의 `$1` 치환으로 한 줄에서 뽑아냅니다. 이 치환은 정상 동작합니다.

## 직접 빌드하기

Python 3 표준 라이브러리만 씁니다.

```sh
python3 scripts/build_shortcut.py          # dist/승차권-캘린더.unsigned.shortcut 생성
python3 -m unittest discover -s tests -v   # 파싱 경계 조건 + 단축어 구조 검사
```

미서명 파일은 아이폰에 바로 설치되지 않습니다. 단축어 앱이 깔린 Mac에서 서명해야 합니다.

```sh
zsh scripts/sign-on-mac.command            # dist/승차권-캘린더.shortcut 생성
```

Finder에서 실행되지 않으면 터미널에 `zsh`를 치고 파일을 끌어다 놓으세요.

`shortcuts sign`은 단축어 사본을 Apple에 보내 검증합니다. 승차권 이미지나 예매 내역은 단축어 파일에 들어 있지 않습니다. 서명은 배포를 위한 절차이지, 실행이 되는지 확인하는 테스트가 아닙니다. ([Apple 문서](https://support.apple.com/guide/shortcuts-mac/apd455c82f02/mac))

### 파일 구성

| 경로 | 내용 |
|---|---|
| `scripts/tickets.py` | 문자 인식 결과를 읽는 정규식과 참조 구현 파서 |
| `scripts/build_shortcut.py` | 단축어 생성 |
| `scripts/build_diagnostic.py` | 기기에서 액션 동작을 확인하는 일회용 진단 단축어 |
| `tests/test_tickets.py` | 파싱 경계 조건, 생성된 단축어의 참조·제어 흐름 구조 |
| `fixtures/synthetic-*.txt` | 잘린 두 절반 형식에 맞춘 **가상의** 테스트 입력 |

테스트는 실제 캘린더에 접근하지 않습니다. 실제 승차권 이미지와 여행 일정 자료는 Git에서 제외합니다.
