# 승차권 → 캘린더

아이폰의 승차권 목록 화면을 읽어 선택한 열차 일정을 캘린더에 등록하는 **기기 검증 전 단축어 초안**입니다. 별도 서버, 로그인, AI API 없이 아이폰의 문자 인식과 캘린더 액션을 사용하도록 구성했습니다.

## 현재 상태

- `dist/승차권-캘린더.unsigned.shortcut`: 생성된 **미서명 원본**. 아이폰에 바로 설치되는 배포 파일이 아닙니다.
- `dist/승차권-캘린더.plist`, `dist/actions.json`: 같은 단축어의 검토 가능한 원본.
- `scripts/sign-on-mac.command`: Mac에서 서명 파일을 만드는 스크립트.
- 로컬 파싱/구조 검사 17개 통과. 실제 Apple Vision OCR 출력(Mac에서 같은 엔진으로 추출)에 대해 3개 카드를 모두 인식하는 것까지 확인했습니다. 단축어 가져오기, 캘린더 생성/중복 검색은 아직 기기에서 검증하지 않았습니다. iOS의 관측 순서는 Mac과 다를 수 있습니다.
- 첨부 화면의 형식을 기준으로 날짜·역·시간을 가상의 값으로 바꾼 3개 카드로 검사했습니다. 아래에 숨겨진 2개 승차권의 내용은 추측하거나 등록하지 않았습니다.

## 설치 준비: Mac에서 한 번

1. 이 프로젝트의 `dist`와 `scripts` 폴더를 같은 상위 폴더 아래에 두고 Mac으로 복사합니다. 원본 승차권 이미지는 서명에 필요하지 않습니다.
2. `scripts/sign-on-mac.command`를 실행합니다. Finder에서 실행되지 않으면 터미널에서 `zsh` 뒤에 파일을 끌어놓고 실행합니다.
3. 생성된 `dist/승차권-캘린더.shortcut` 파일을 AirDrop 등으로 아이폰에 전달합니다.
4. 아이폰에서 파일을 열고 단축어를 추가합니다. 저장할 캘린더는 **‘집’으로 지정되어 있습니다**. 다른 캘린더에 넣으려면 편집 화면의 ‘새로운 이벤트 추가’ 액션에서 바꾸세요. 가져오기 질문이 뜨면 거기서 골라도 됩니다. 기기의 캘린더 이름이 ‘집’이 아니면 반드시 편집 화면에서 지정해야 합니다.
5. 먼저 승차권 **캡처 한 장을 공유 메뉴로 전달**해서 인식 결과를 확인합니다. 중복 확인에는 캘린더 읽기 권한도 필요합니다.
6. 검증 후 `설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭 또는 삼중 탭`에 ‘승차권 캘린더’를 연결합니다.

Mac의 `shortcuts sign`은 단축어 사본을 Apple에 보내 검증합니다. 원본 이미지와 예매 내역은 이 단축어 파일에 포함되지 않습니다. 서명은 파일 배포를 위한 절차이며, 실행 성공을 검증하는 테스트는 아닙니다.

공식 설명: https://support.apple.com/guide/shortcuts-mac/apd455c82f02/mac

## 사용

승차권 목록에서 날짜, 출발역, 도착역, 출발 시간, 도착 시간이 전부 보이게 합니다. 인식한 후보 목록에서 날짜·역·시간을 확인하고 저장할 승차권을 선택합니다. 처음에는 필요한 권한을 허용해야 합니다.

실행 방법은 두 가지입니다.

- **공유 시트**: 승차권 캡처를 공유 메뉴에서 이 단축어로 넘깁니다. 기기에서 동작을 확인한 경로입니다.
- **뒷면 탭**: 먼저 시스템 제스처로 **스크린샷을 찍은 뒤** 뒷면을 탭합니다. 단축어가 가장 최근 스크린샷 한 장을 읽습니다. iOS 단축어에는 화면을 직접 캡처하는 액션이 없어서(‘스크린샷 찍기’는 macOS 전용) 이 순서가 필요합니다. 스크린샷을 먼저 찍지 않으면 엉뚱한 이미지를 읽고 후보를 찾지 못합니다. 이 경로는 아직 기기에서 검증하지 않았습니다.

아래 승차권은 직접 스크롤한 다음 다시 실행합니다. 카드가 화면 경계에 걸리면 카드 전체가 보이도록 조금 조정하세요. 여러 캡처를 사진 앱에서 한꺼번에 선택해 공유하는 입력도 구성되어 있지만, 실제 기기 동작은 확인해야 합니다.

- 날짜·출발역·도착역·출발/도착 시간이 같은 일정은 이벤트 메모의 식별자로 검색해 중복을 건너뜁니다. 날짜만 같고 출발 시간이 다른 승차권은 별개 일정입니다.
- 이전에 이 단축어로 만든 이벤트가 대상입니다. 수동으로 만든 일정에는 식별자가 없어 자동 중복 판별되지 않습니다. 다른 캘린더로 복사하거나 메모의 식별자를 삭제하면 동작이 달라질 수 있습니다.
- 제목은 ‘열차 서울 → 부산’와 같이 저장합니다. 화면에 열차 종류가 없어 KTX/SRT를 추측하지 않습니다.
- 출발/도착은 한국 시간 `+09:00`으로 전달합니다. 캘린더 앱의 표시 시간대에 따라 화면의 시각은 달라질 수 있습니다.
- 30분 전 알림을 설정합니다.
- 완료 화면은 추가/중복/시간·구간 확인 필요 건수를 표시합니다. 인식 자체에 실패한 카드나 화면 밖 승차권은 이 건수에 포함되지 않습니다.

## 지원 범위와 남은 검증

제공된 목록 화면처럼 `YYYY.MM.DD`, ‘기차 승차권’, 역 두 개와 시간 두 개가 있는 카드를 대상으로 합니다. OCR이 행 순서(역·역·시간·시간) 또는 열 순서(역·시간·역·시간)로 반환하는 경우를 처리합니다.

Apple Vision은 화면 텍스트를 카드 단위가 아니라 공간 순서로 반환합니다. 실제 출력에서는 필터 칩(‘이용권’, ‘정기권’)과 하단 탭바(‘홈’)가 카드 헤더와 역 사이에 끼어들고, 역 사이의 회색 화살표가 ‘ㅗ’처럼 인식됩니다. 그래서 헤더와 역 사이의 **숫자 없는 줄은 건너뛰고**, 역·시간 사이 구분자는 한글 음절과 숫자만 아니면 허용합니다. 날짜와 시간 줄에는 항상 숫자가 있으므로 이 건너뛰기가 옆 카드까지 넘어가지는 않습니다.

카드 사이 순서가 섞이거나 역 이름 글자를 틀리게 인식하는 경우까지 보장하지 않습니다. 인식한 역 이름의 실재 여부는 조회하지 않으므로 선택 화면에서 확인해야 합니다.

이 초안은 자정을 넘는 이동, 승차권 상세 화면, 푸시 문구, 2자리 연도, 월/일 한 자리 표기를 지원하지 않습니다. 같은 역이거나 도착 시간이 출발 시간보다 이르거나 같은 후보는 등록하지 않습니다. 취소·변경은 자동 동기화하지 않습니다.

기기 검증 순서:

1. 새 테스트 캘린더를 선택하고 제공된 캡처를 공유합니다. 후보 3개와 출발/도착 시간을 확인합니다.
2. 먼저 1개만 선택해 생성된 이벤트의 날짜·시간·캘린더·30분 전 알림을 확인합니다.
3. 같은 캡처를 다시 실행해 이미 등록한 항목은 중복으로 표시되는지 확인합니다.
4. 아래로 스크롤한 새 화면에서 겹치는 항목은 건너뛰고 새로운 승차권만 추가되는지 확인합니다.
5. 여러 이미지 공유, 뒷면 탭의 현재 화면 캡처, 캘린더 권한 거절/취소 동작을 확인합니다.

문제가 생기면 실패한 액션 이름과 ‘이미지에서 텍스트 추출’ 결과를 확인해야 합니다. 로컬 검사를 통과했다고 이 기기 검증까지 완료된 것은 아닙니다.

## 재생성 및 로컬 검사

Python 3 표준 라이브러리만 사용합니다.

```sh
python3 scripts/build_shortcut.py
python3 -m unittest discover -s tests -v
```

`fixtures/synthetic-cards.txt`는 화면 형식에 맞춘 가상의 테스트 입력이며 Apple OCR의 실제 출력이 아닙니다. 실제 승차권 이미지와 원래 여행 일정 자료는 Git에서 제외합니다. `tests/test_tickets.py`는 파싱의 경계 조건과 생성된 단축어의 참조/제어 흐름 구조를 확인합니다. 실제 캘린더에는 접근하지 않습니다.
